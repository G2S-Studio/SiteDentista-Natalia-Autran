Dúvidas frequentes

Antes de agendar

Não encontrou sua pergunta? Fale com a gente pelo WhatsApp.

Como é a primeira consulta?

É uma consulta de avaliação: conversamos sobre suas queixas e seu histórico, fazemos o exame clínico e, ao final, você sai sabendo quais são as opções de tratamento para o seu caso.

A Cannabis Medicinal serve para todo mundo?

Não. A indicação depende de uma avaliação individual — do quadro, do histórico e de outros medicamentos em uso. Quando não é indicada, outras abordagens são discutidas com você.

Preciso fazer os três tratamentos?

Não. Muitos pacientes vêm apenas para ortodontia ou clínica geral. As abordagens integrativas são sempre uma opção, nunca uma obrigação.

O aparelho invisível funciona para qualquer caso?

Funciona para boa parte dos casos, mas só a avaliação ortodôntica diz qual aparelho é o mais adequado para você.
